Activer les comptes (connexion)

À quoi ça sert

  • Chaque personne crée son compte (e-mail + mot de passe).
  • Tout ce qui est saisi est sauvegardé en ligne : on retrouve tout son historique sur l’iPhone, l’iPad ou n’importe quel appareil, en se connectant.
  • Les appareils se synchronisent en temps réel ; hors ligne, l’app continue de marcher et envoie les changements au retour du réseau.
  • Chaque compte ne voit que ses propres données.

Les comptes utilisent Firebase (Google), gratuit pour cet usage (offre « Spark », sans carte bancaire). Il faut le configurer une seule fois, environ 10 minutes.

Étapes

  1. Ouvre console.firebase.google.com avec un compte Google, puis Créer un projet (nom : par exemple seche). Google Analytics n’est pas nécessaire.
  2. Menu Authentication → Commencer → onglet Sign-in method → E-mail/Mot de passe → activer → Enregistrer.
  3. Toujours dans Authentication → Paramètres → Domaines autorisés → Ajouter un domaine : ambregly.github.io.
  4. Menu Firestore Database → Créer une base de données → emplacement en Europe (par ex. europe-west9, Paris) → mode production.
  5. Dans Firestore → onglet Règles, remplace tout le texte par celui-ci, puis Publier : 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
    Ces règles garantissent que chaque compte ne peut lire et modifier que ses propres données.
  6. Roue dentée ⚙ → Paramètres du projet → section Vos applications → icône Web </> → nom Sèche → Enregistrer l’application (Firebase Hosting n’est pas nécessaire). Firebase affiche un bloc const firebaseConfig = { … }.
  7. Copie ce bloc dans le fichier js/firebase-config.js du dépôt GitHub (bouton crayon « Edit » sur github.com), à la place de export const firebaseConfig = null; : 
    export const firebaseConfig = {
  apiKey: "AIza…",
  authDomain: "seche-xxxx.firebaseapp.com",
  projectId: "seche-xxxx",
  storageBucket: "seche-xxxx.firebasestorage.app",
  messagingSenderId: "…",
  appId: "1:…:web:…"
};
    Ou envoie simplement ce bloc à Claude, qui fera la modification. Ces valeurs ne sont pas secrètes : la sécurité vient des règles de l’étape 5.
  8. Après la publication (1–2 minutes), ouvre l’app, touche l’icône personne en haut à droite → Créer un compte. Si des données avaient déjà été saisies sur l’appareil, l’app propose de les copier dans le compte.

Bon à savoir

  • Mot de passe oublié : bouton « Mot de passe oublié ? » sur l’écran de connexion (un e-mail est envoyé).
  • Plusieurs personnes sur le même iPad : se déconnecter, puis l’autre personne se connecte avec son compte.
  • Le journal des actions (bouton horloge) et « Annuler » fonctionnent aussi avec un compte : une annulation est synchronisée sur tous les appareils.
  • Limites gratuites Firebase (largement suffisantes) : 1 Go de données, 20 000 écritures et 50 000 lectures par jour.
