Notifications (rappels)

Comment ça marche

Toutes les heures, une tâche automatique sur GitHub (.github/workflows/notifications.yml) regarde les données de chaque compte qui a activé les notifications et envoie, si besoin :

  • Repas (21 h par défaut) : si le petit-déjeuner, le déjeuner ou le dîner ne sont pas notés.
  • Séance (19 h) : les jours de musculation prévus, si la séance n’est pas validée.
  • Pesée (8 h) : tous les 5 jours, puis chaque semaine quand la progression est bonne (perte de 0,4 à 1,2 % du poids par semaine sur 3 semaines).

Heures et fréquence se règlent dans l’app : icône personne → Notifications.

Configuration (une seule fois, sur ordinateur de préférence)

La tâche automatique a besoin de deux « secrets » GitHub. Ils ne sont visibles par personne une fois enregistrés.

  1. Clé Firebase du serveur : sur console.firebase.google.com, projet fitness → roue dentée ⚙ → Paramètres du projet → onglet Comptes de service → Générer une nouvelle clé privée → Générer. Un fichier .json est téléchargé. Ne l’envoie à personne (il donne accès à toutes les données).
  2. Sur GitHub, dépôt Fitness → Settings → Secrets and variables → Actions → New repository secret :
    • Name : FIREBASE_SERVICE_ACCOUNT ; Secret : ouvre le fichier .json avec un éditeur de texte (Bloc-notes, TextEdit…) et colle tout son contenu. → Add secret.
  3. Encore New repository secret :
    • Name : VAPID_PRIVATE_KEY ; Secret : la clé donnée par Claude dans la conversation. → Add secret.
  4. Supprime ensuite le fichier .json téléchargé.

Activer sur l’iPhone / l’iPad

  1. iOS 16.4 ou plus récent. L’app doit être installée : dans Safari, Partager → Sur l’écran d’accueil.
  2. Ouvre l’app depuis l’icône de l’écran d’accueil, connecte-toi à ton compte.
  3. Icône personne → Notifications → Activer les notifications sur cet appareil → Autoriser.
  4. Une notification « Notifications activées ✅ » confirme que tout marche. À faire sur chaque appareil qui doit recevoir les rappels.

Pas de notification ? Vérifie Réglages de l’iPhone → Notifications → Sèche, et que le mode Concentration ne les bloque pas.
